# Home Network Infrastructure

**Project Status:** Operational — Configuration & Documentation in Progress

**Project Type:** Physical Networking | Network Infrastructure | Wireless Networking

---

## 1. Project Overview

This project involved designing and deploying a residential wired and wireless network to improve connectivity, reliability, and wireless coverage throughout the home.

The original network relied primarily on an AT&T Fiber gateway located near the front of the house. Due to the distance between rooms and physical obstructions, wireless connectivity was inconsistent in certain areas.

To address these limitations, I installed structured Cat6 Ethernet cabling, deployed a centrally located wireless access point, and integrated a managed network switch with PoE capability to support wired and wireless connectivity.

The network also serves as a practical environment for exploring network administration, troubleshooting, wireless optimization, and security configurations.

## 2. Project Objectives

- Improve wireless coverage throughout the home.
- Provide reliable wired Ethernet connectivity to multiple rooms.
- Deploy a dedicated access point for improved wireless performance.
- Implement a managed switch to support network connectivity and future configurations.
- Gain hands-on experience with network installation, administration, and troubleshooting.
- Validate network performance and document the implementation.

## 4. Implementation

### Physical Infrastructure

- Planned Ethernet cable runs from the gateway location to rooms requiring wired connectivity.
- Routed Cat6 cabling through accessible attic space.
- Terminated and organized Ethernet cable runs using a keystone patch panel, allowing structured connections between the permanent cabling and network switch.
- Installed Ethernet keystone jacks and wall plates.
- Used network cable testing equipment to verify cable terminations.
- Installed a hallway-mounted wireless access point to improve coverage.
- Connected network equipment and wired devices through a managed Ethernet switch.

### Network Configuration

- Integrated the managed switch with the existing AT&T gateway.
- Connected and configured the TP-Link EAP723 wireless access point.
- Established wired Ethernet connectivity to desktop devices.
- Verified client connectivity and internet access.

## 5. Initial Results

- Established working Ethernet connections in multiple rooms.
- Improved wireless coverage in previously underserved areas.
- Achieved approximately 500–600 Mbps during initial wired internet speed testing which matched bandwidth capability.
- Created a foundation for future network administration and security improvements.
