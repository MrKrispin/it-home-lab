# Ubuntu Server Administration Lab

## Purpose

Build a virtual Ubuntu Server environment to practice Linux administration, remote access, permissions, services, troubleshooting, security controls, and backups.

## Environment

- Host OS: Windows 11
- Virtualization platform: VirtualBox
- Guest OS: Ubuntu Server
- CPU: 2 virtual cores
- Memory: 4 GB
- Storage: 40 GB dynamically allocated
- Network mode: NAT

## Completed Tasks

### Initial Deployment

- Created the Ubuntu Server virtual machine
- Installed Ubuntu Server
- Configured LVM-based storage
- Created a non-root administrative user
- Installed OpenSSH Server
- Completed the initial login

## Current Phase

### Baseline System Verification

Current objectives:

- Verify system identity and operating system information
- Inspect disk, filesystem, and LVM configuration
- Verify IP addressing and routing
- Update installed packages
- Confirm the SSH service is running
- Test remote SSH administration from the Windows host

## Upcoming Tasks

### Linux Administration

- Configure file ownership and permissions
- Manage processes and services

### Networking and Security

- Review network configuration

### Recovery and Documentation
