# Ubuntu Server Administration Lab

## Purpose

Build a virtual Ubuntu Server environment to practice Linux administration, remote access, permissions, services, troubleshooting, security controls, and backups.

## Environment

- Host OS: Windows 11
- Virtualization platform: VirtualBox
- Guest OS: Ubuntu Server
- CPU: 2 virtual cores
- Memory: 4 GB
- Storage: 40 GB dynamically allocated
- Network mode: NAT

## Current Progress

- Confirmed VirtualBox is working
- Downloaded the Ubuntu Server ISO
- Prepared an organized location for VM files

## Planned Tasks

- Install Ubuntu Server
- Update packages
- Create users and groups
- Configure SSH
- Practice Linux permissions
- Install and manage a web service
- Configure the firewall
- Review logs
- Test backup and restore
- Document troubleshooting
